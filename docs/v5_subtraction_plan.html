一、方法架构总览

将原有 8 个独立方法 精简为 3 个方法族 + 1 个独立方法，消除并列冗余，明确二选一关系。

方法族 名称 内部结构 触发条件 置信度
族① 校内划线换算 1A1B 二选一
1A: 双模块完整换算（语数英+选科各自独立划线）
1B: 仅语数英划线 → 450→750 等比例放大		 升级 Sheet 有校内划线数据 A 或 B
族② 外部参考映射 2A 三选一
2A-1: 分数线对照法（特控线锚点）
2A-2: 人数校准法（校内排名→高考排名）
2A-3: 百分位锚定法（全市/联盟排名）		 有外部参考数据（特控线/排名） A 或 B
族③ 校内排名映射 三选一
3-1: 校内排名对照法（有本校对照表）
3-2: 校排阈值估算法（有升级Sheet人数）
3-3: 校排名估算（无对照表，低精度）		 有校内排名数据 A / B / C
方法④ 单科排名对照法 独立方法
各选科校内单科排名 → 对照表 → 等效分		 有单科对照表 + 各科校内排名 A

族间关系

  • 族① vs 族②：并列关系。族①基于校内划线（更精准），族②基于外部参考（更通用）。两者同时可用时，族①为优先主方法，族②参与交叉验证。
  • 族①内部 1A/1B：二选一。有选科独立划线 → 1A（A级）；仅语数英划线 → 1B（B级，等比例放大）。
  • 族②内部三选一：按精度排序，2A-1 > 2A-2 > 2A-3，第一个可用者胜出。
  • 族③：校内排名专用，与族①②互补。仅当族①②均不可用时作为主方法。
  • 方法④：独立运行，仅计算选科部分，不单独决定总分。可与任意族配合使用。

v4 → v5 变更要点

  • 跨次回退折扣：从指数衰减 0.85^n 改为固定 0.9。原方案跨1次=0.85、跨2次=0.72，衰减过快；固定0.9更合理（跨1次=0.9、跨2次=0.9，不因跳过次数而过度惩罚）。
  • 计算详情展示：detail 字段从"一句话摘要"改为分步骤展示，每步包含公式+数值+结果。
  • 技术回滚场景：场景一明确展示选科无校内划线时的跨次回退路径。

方法选择：族① 1A 模式

检测到语数英综合有特控线(270) + 浙大线(300)，且有选科独立划线（物理、化学）
→ 进入 1A 双模块完整换算模式（A级）
→ 技术无独立划线 → Module 2 中走跨次回退路径

逐步计算

Module 1：语数英（450分制 → 等效）

步骤 1：计算学生语数英原始分总和
学生语数英 = 语文115 + 数学120 + 英语115 = 350 分
步骤 2：读取校内划线
校特控线 = 270 分（上线500人）
校浙大线 = 300 分（上线150人）
步骤 3：计算线上比例（特控线 → 浙大线 区间内的位置）
ratio = (学生分数 - 特控线) / (浙大线 - 特控线)
ratio = (350 - 270) / (300 - 270) = 80 / 30 = 2.667
→ 2.667 > 1.0，说明学生超过浙大线，封顶 ratio = 1.0
步骤 4：基础等效分（线性插值 特控目标 ↔ 浙大目标）
基础等效 = 特控目标 + (浙大目标 - 特控目标) × ratio
基础等效 = 341 + (382 - 341) × 1.0 = 341 + 41 = 382.0 分
步骤 5：超额衰减奖励（超过浙大线的部分，按衰减系数×0.3计算）
超额 = 学生分数 - 浙大线 = 350 - 300 = 50 分
每分价值 = (浙大目标 - 特控目标) / (浙大线 - 特控线) = 41 / 30 = 1.367 分/分
衰减奖励 = 超额 × 衰减系数(0.3) × 每分价值 = 50 × 0.3 × 1.367 = 20.5 分
步骤 6：最终语数英等效分
等效 = min(基础等效 + 衰减奖励, 语数英上限430)
等效 = min(382.0 + 20.5, 430) = min(402.5, 430) = 402.5 分
置信度 = A级（特控线+浙大线双线齐全）

Module 2-1：物理（78分，有特控线72 + 浙大线85）

步骤 1：读取校内划线
校特控线 = 72 分，校浙大线 = 85 分
步骤 2：计算线上比例
ratio = (78 - 72) / (85 - 72) = 6 / 13 = 0.4615
→ 0 < 0.4615 < 1.0，位于特控线与浙大线之间，正常插值
步骤 3：等效分
等效 = 选科特控目标 + (选科浙大目标 - 选科特控目标) × ratio
等效 = 90 + (96 - 90) × 0.4615 = 90 + 2.77 = 92.8 分
置信度 = A级（双线齐全）

Module 2-2：化学（82分，有特控线75 + 浙大线88）

步骤 1：读取校内划线
校特控线 = 75 分，校浙大线 = 88 分
步骤 2：计算线上比例
ratio = (82 - 75) / (88 - 75) = 7 / 13 = 0.5385
→ 0 < 0.5385 < 1.0，位于特控线与浙大线之间，正常插值
步骤 3：等效分
等效 = 90 + (96 - 90) × 0.5385 = 90 + 3.23 = 93.2 分
置信度 = A级（双线齐全）

Module 2-3：技术（88分原始分，本次无校内划线）跨次回退

步骤 1：检测校内划线
技术在升级 Sheet 中无特控线、无浙大线 → 无法直接换算
步骤 2：检测赋分
本次考试技术无赋分 → 无法使用赋分直映
步骤 3：跨次回退 — 查找上一次考试的技术数据
读取 成绩总表.xlsx，从最新一条往回搜索
跳过当前"期末考试"记录
找到上次"月考"记录：选科3名称=技术，选科3赋分=85（A级）
跳过考试次数 n = 1
步骤 4：折扣计算（v5 修改：固定0.9，不再用 0.85^n 指数衰减）
折扣 = CROSS_EXAM_DISCOUNT = 0.9（固定值）
# v4 旧逻辑：discount = 0.85^1 = 0.85（衰减过快）
# v5 新逻辑：discount = 0.9（固定，不随跳过次数递减）
步骤 5：技术等效分
技术等效 = 上次赋分 × 折扣 = 85 × 0.9 = 76.5 分
置信度 = C级（跨次回退，精度降低）
提示：建议补录本次技术赋分后重新计算以获得更精确结果

三、场景二：月考（仅语数英划线）

输入数据
考试名称10月月考
学生成绩语数英320分；物理75分（赋分88）；化学70分（赋分85）；技术80分（赋分82）
校内划线仅语数英综合：特控线260分（上线450人）。无选科独立划线

方法选择：族① 1B 模式

检测到语数英综合有特控线(260)，但无选科独立划线
→ 进入 1B 仅语数英划线模式（B级）
→ 选科使用赋分直映（有赋分则直接使用）

逐步计算

Module 1：语数英（仅有特控线，单点放缩）

步骤 1：计算学生语数英
学生语数英 = 320 分
步骤 2：单点比例放缩（无浙大线，仅用特控线）
ratio = 学生分数 / 特控线 = 320 / 260 = 1.231
→ ratio > 1.0，封顶为 1.0
步骤 3：基础等效
基础等效 = 特控目标 × ratio = 341 × 1.0 = 341.0 分
步骤 4：超额衰减奖励
超额 = 320 - 260 = 60 分
每分价值 = 特控目标 / 特控线 = 341 / 260 = 1.312
衰减奖励 = 60 × 0.3 × 1.312 = 23.6 分
步骤 5：最终等效
语数英等效 = min(341 + 23.6, 430) = 364.6 分
置信度 = B级（仅有特控线，无浙大线）

Module 2：选科（赋分直映）

物理：赋分88 → 等效88.0 A级
化学：赋分85 → 等效85.0 A级
技术：赋分82 → 等效82.0 A级
选科有赋分时直接使用赋分作为等效分（赋分本身就是全省排名换算结果）。

逐步计算

校内排名对照法

步骤 1：读取校内排名
原始排名 = 85名
重点班未参考人数 = 0（无补算）
校准后排名 = 85 + 0 = 85名
步骤 2：在本校对照表中查找
对照表数据（示例）：
排名80 → 高考总分632
排名90 → 高考总分618
85 位于 [80, 90] 之间 → 线性插值
步骤 3：线性插值
ratio = (85 - 80) / (90 - 80) = 5 / 10 = 0.5
等效分 = 632 + (618 - 632) × 0.5 = 632 - 7 = 625.0 分
置信度 = A级（有本校对照表）
