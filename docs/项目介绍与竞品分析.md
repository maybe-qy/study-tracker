# study-tracker 项目介绍与竞品分析

[study-tracker](https://github.com/maybe-qy/study-tracker) 是一个面向中国高中学生的学业追踪与等效分计算工具，专为浙江新高考（选考赋分制）设计。MIT 开源协议，Python 3.9+，完全离线运行。核心目标是把校内考试成绩换算成高考等效分，帮助学生更准确地评估自己的真实水平。

## 核心功能

| 功能 | 说明 |
|------|------|
| 成绩录入 | 逐字段录入考试科目成绩、排名、特控线，自动校验总分一致性 |
| 等效分计算 | 8 种方法按优先级自动选择，加权融合，标注置信度和误差区间 |
| 趋势分析 | 等效分时间序列追踪，EWMA 预测状态（积极/正常/消极），波动风格分类 |
| 单科追踪 | 语文/数学/英语/选科独立追踪，动态赋分计算 |
| 院校定位 | 目标院校差距分析，院校层次梯队定位 |
| HTML 报告 | 8 份独立报告一键生成，按日期降序排列 |

## 8 种等效分计算方法（核心亮点）

系统按优先级自动选择，加权融合（A=1.0 / B=0.8 / C=0.5 / D=0）：

- **A 级**（±5 分）：分数线对照法、校内排名对照法、单科排名对照法、排名锚定法
- **A/B 级**（±5-10 分）：双模块换算法
- **B 级**（±10 分）：人数校准法、校排阈值估算法
- **C 级**（±15 分）：校排名估算

## 使用方式

- **AI 助手模式（推荐）**：把项目链接发给豆包/ChatGPT/Claude，AI 自动完成部署、录入、计算、生成报告
- **命令行模式**：`git clone` → `pip install -r requirements.txt` → 运行 Python 脚本

## 竞品格局

### GitHub

GitHub 上与高考成绩相关的开源项目仅找到 2 个，其中只有 1 个做等效分计算：

| 项目 | 语言 | Stars | 定位 |
|------|:----:|:-----:|------|
| [Gaokao-equivalent-score-calculation](https://github.com/aime4eve/Gaokao-equivalent-score-calculation) | Python | 1 | 湖南历史类等效分计算，单省份/单科类 |
| [Gaokao-score-distribution](https://github.com/sdgedfegw/Gaokao-score-distribution) | — | 2 | 1996-2024 一分一段数据仓库（非计算工具） |

唯一的等效分项目限定单一省份+科类，不是通用工具。

| 项目 | 简介 |
|------|------|

| StudentScoreAnalysis | 多次考试成绩分析，Excel 报告生成 |

## 结论

整个市场格局很清晰：

- **志愿填报产品**（夸克高考/志愿智答）主要做高考后的志愿填报，模考等效分只是引流功能，不开放、不可定制
- **校方工具**（穿杨同学/具才/易点/分查查）面向学校或教师，做批量成绩统计和教务分析，个人学生无法自主使用
- **开源项目**仅 2 个 GitHub + 3 个 Gitee，一个限定单省份，一个是数据仓库，其余为教务系统
- **没有一个面向学生个人 + 开源 + AI 助手分发的等效分计算工具**

study-tracker 是唯一一个将"校内排名→高考等效分"做到底层算法的开源项目，填补了个人学生 + 本地数据 + AI 分发的空白。
