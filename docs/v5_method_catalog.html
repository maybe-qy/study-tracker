说明：下面列出当前系统中所有可用于计算等效分的方法。每个方法标明了数据来源、计算公式、当前置信度、精度边界。所有原始数据从 Excel 读取，所有输出的单位是"高考等效分(750分制)"。 方法编号 M01-M13 仅为索引，不代表优先级。

一、总分级方法（直接输出总等效分）

M01双模块换算法method_two_module()
数据来源
校内升级Sheet：特控线分段 + 浙大线分段
当前置信度
A 或 B
精度边界
±5分(A级) / ±10分(B级)
触发条件
需语数英综合有特控线

计算逻辑：

Module 1 语数英(450分) → 校特控线/浙大线 → 比例插值 → 等效分
Module 2 各选科(100分) → 各科独立划线 → 比例插值 → 等效分×N
总分 = 语数英等效 + 选科1等效 + 选科2等效 + 选科3等效
内部还有 1A(有选科划线) / 1B(仅语数英划线) 两种子模式
M02分数线对照法（等比例放缩）method_score_line()
数据来源
考试特控线 + 省级特控线历史数据
当前置信度
A
精度边界
±5分
触发条件
需知本次考试特控线(问老师)

计算逻辑：

考试总分 → (750-高考特控线)/(750-考试特控线) → 等比例放缩 → 等效分
使用高考特控线作为固定锚点，考试特控线作为浮动锚点，两点间线性插值
M03人数校准法method_population_calibration()
数据来源
校内排名 + 校内特控线上线人数 + 高考特控线对应人数
当前置信度
B
精度边界
±10分
触发条件
需校内排名+门槛Sheet有特控线上线人数

计算逻辑：

校内排名 × k = 高考特控线人数/校内特控线上线人数 → 估算高考排名 → 查一分一段表 → 等效分
核心假设：校内特控线上线人数与高考特控线对应人数的比例关系可校准排名
M04校排阈值估算法method_school_threshold()
数据来源
升级Sheet（特控线/浙大线 + 对应上线人数）+ 学校总人数
当前置信度
B
精度边界
±10分
触发条件
需升级Sheet有特控线+浙大线+上线人数

计算逻辑：

语数英分数 → 特控线~浙大线区间定位 → 估算校内排名 → ×学校类型系数 → 估算高考排名 → 查一分一段表 → 等效分
与 M03 的区别：M03 用特控线上线人数直接校准，M04 用分数区间定位校内排名
M05校内排名对照法method_school_lookup()
数据来源
本校对照表_总分 + 校内排名
当前置信度
A
精度边界
±5分
触发条件
需有本校对照表(排名→高考总分映射)

计算逻辑：

校内排名 → 本校对照表查找 → 精确匹配/线性插值 → 等效分
最直接的校内排名方法。对照表由学校历史数据构建，排名→高考总分直接映射
M06排名锚定法（百分位法）method_percentile()
数据来源
全市排名+总人数 / 联盟排名+总人数 + 省级一分一段表
当前置信度
A
精度边界
±5分
触发条件
需有全市或联盟排名+总人数

计算逻辑：

全市/联盟排名 → 百分位 = 1 - 排名/总人数 → 一分一段表定位 → 等效分
取决于排名范围：全市排名比联盟排名更精确，联盟排名比校内排名更精确
M07校排名估算method_school_estimate()
数据来源
校内排名+学校总人数+学校类型+一分一段表
当前置信度
C
精度边界
±15分
触发条件
无对照表时，仅校排名+总人数可用

计算逻辑：

校内排名/总人数 × 学校类型系数(省重点0.3~普通1.5) → 估算全市排名 → 查一分一段表 → 等效分
精度最低的总分方法，学校类型系数是经验值，误差大
M08单科排名对照法method_school_subject_lookup()
数据来源
各科单科对照表 + 各科校内排名
当前置信度
A
精度边界
±5分
触发条件
需有单科对照表+各科校内排名

计算逻辑：

选科1校内排名 → 物理对照表查 → 等效分1
选科2校内排名 → 化学对照表查 → 等效分2
选科3校内排名 → 技术对照表查 → 等效分3
总分 = 各科等效分之和（单独输出，不包含语数英）
只输出选科等效分，语数英需另外计算。可与任意总分方法配合

四、当前已有问题的总结

  1. 族② 三选一不合理 — 校排名(M03/M04/M05/M07) 和 联盟排名(M06) 应该各自独立算分，不是只能选一个。多个排名数据同时存在时，每个都算一遍，交叉验证。
  2. 置信度系统混乱 — 当前A/B/C/D分级没有统一标准。有的方法因为数据来源好而置信度高（如M05对照表→A），但M06联盟排名也是A，M07校内排名估算却是C，同样是"排名"维度却不同级。
  3. 校排名方法太多 — M03/M04/M05/M07 四条方法都使用校内排名，但互相之间的关系不清晰（并列？选一？优先级？）。
  4. M08 单科排名对照法地位模糊 — 它只输出选科等效分，不输出总分，不能直接和其他总分方法并列。
  5. M11/M12/M13 不是独立方法 — 它们是在总分确定后分配各科的手段，不是产生新数据的计算方法。
