# PRD v1.0 与现有实现（v5.1.1）差异分析报告

- **分析对象**：《学业追踪与等效分报告系统 · 产品需求文档 v1.0》（文档状态：需求定稿，待开发）
- **对照实现**：仓库 `study-tracker`，Git 版本 `v5.1.1`（commit `915f0c4`）
- **分析方法**：逐条比对 PRD 的 M1–M7、数据结构、置信度、交互、非功能、技术架构、验收标准；以源码、测试与 `CHANGELOG.md` 为证据
- **本报告只做差异分析，未修改任何代码**
- **测试基线**：`pytest tests/ -q` → **128 passed, 2 failed, 4 skipped**

> 状态图例：✅ 一致 ｜ ⬆️ 实现已超越 PRD ｜ ⚠️ 部分差异 ｜ ❌ 直接冲突 ｜ ⛔ PRD 要求但未实现

---

## 0. 总体结论

1. **PRD v1.0 严重滞后于实现。** PRD 自称"待开发"，但仓库已是 v5.1.1，经历 v4.x → v5.0.0 → v5.1.1 多轮重构。PRD 描述的是**初始蓝图**，而非当前状态。
2. **多数差异属于"有意升级"，不是缺陷。** 例如：8 个 HTML → 2 个 Tab 报告、4 种方法 → 8 方法/3 方法族、新增人数校准法与双模块换算法，均记录在 `CHANGELOG.md`。
3. **少数 PRD 要求未落地**：MBTI/职业偏好存档、`波动分析记录.xlsx`、草稿中断恢复、6 科独立对照表、6 科独立报告。
4. **存在若干"文档与代码不一致"和 2 个失败测试**，属于需要收口的技术债（详见 §8）。

**一句话**：若以 PRD v1.0 为验收标准，实现"对不上"；若以实现为准，PRD 需要升版重写（建议 v2.0）。

## 4. 置信度体系

- A/B/C/D 四级定义、趋势/波动权重（A1.0/B0.8/C0.5/D0）、展示规则：**基本一致**。
- **冲突点**：C 级。PRD §3.4.5 要求 C 级也返回估算区间；实现 v4.0 起设"置信度门槛"——**仅 C 级可用时直接 `insufficient_data`**，理由（±15 分无决策价值）在 [calculation_methods.md](file:///workspace/skill/references/calculation_methods.md#L16-L20) 有说明。
- **增强**：多方法 ≥3 且收敛（差异 ≤3 分）时**动态升级置信度**（C→B、B→A）；双模块换算法采用"木桶原理（取最低）"避免虚假 A 级。这两点 PRD 均无。
